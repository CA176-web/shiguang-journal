# 拾光日记 使用说明

适用于拾光日记 0.9.1 试用版和 Windows 11 x64。更新于 2026 年 11 月 20 日。

在侧栏选择 **时间线**，可按月浏览日记。点上、下箭头跳到相邻有记录的月份。点 **选择日期** 可定位到当天的第一篇记录。当天为空时，会定位到此前最近的一篇；所选日期早于全部记录时，会显示最早一篇。点卡片进入编辑，点 **新日记** 开始写。

在 **设置 → 外观** 中可选择一周的第一天、时间线是否显示完整正文和标签，以及日历和时间线是否显示图片预览。新日记库默认使用蓝色主题。已有日记库沿用原来保存的颜色，要使用新版蓝色请选择第一个蓝色色块。

在 **标签** 页选择标签或人物，可以看到关联的日记。“排序”可以选择按字母、使用次数或最近使用排序，重新打开后会沿用所选顺序。最近使用依据日记日期和时刻；修改旧日记不会把它的标签当作今天使用。**关于 → 日记管理** 提供导入、备份、回收站和锁定等操作。

在 **设置 → 外观** 打开 **显示日记时间**，时间线便会显示每篇的时刻。在 **标签 → 标签颜色…** 选择标签和颜色，也可右键标签设置。**日历日期颜色** 可以选择主题色、标签或评分。有照片且开启预览时显示照片，关闭预览即可查看底色。同一天有多个标签时，按日记时刻、标签名称选首个有颜色的标签；按评分着色时使用当天最早有评分的日记。评分色值和此取色规则为拾光的实现。

**设置 → 外观 → 字体** 可选择已安装的字体，作用于导航、日历、时间线、编辑器和弹窗。正文字号单独控制编辑区。附件页的方格随窗口宽度调整。编辑器的格式工具栏会标明已启用或混合的格式，下划线和删除线可以叠加，也可单独取消。

**同步** 支持拾光客户端之间的 Google Drive 或 WebDAV 同步。要读取电脑上正版 Diarium 已同步的数据，打开 **设置 → 服务 → 从本机 Diarium 导入**。该操作是单向导入。[拾光 Google Drive 首次配置](docs/Google-Drive首次配置.md)

**设置 → 服务 → Diarium 合并备份…** 提供双方日记与附件的本机合并。选择正版同步后的数据库或完整 .diary 备份，点击 **预览合并** 查看条数，再 **生成合并备份**。结果会写入拾光，并保存成新的 .diary 文件。双方同时修改的日记保留冲突副本。生成文件仍需在正版导入后，通过正版 Google Drive 同步到手机；这一实机流程尚未验收，使用前请保留正版备份。当前已配对条目的删除、日期移动，以及人物、追踪器、事件和模板的双向编辑仍有适配限制，预览会提示。手机安卓 Diarium 与拾光之间的自动双向同步尚未实现。

## 1. 打开程序

新电脑可直接运行拾光日记 0.9.1 的 x64 安装包。安装向导提供开始菜单入口和可选桌面快捷方式。升级前先保存并退出拾光日记。换电脑迁移方法见随安装包提供的《安装与换电脑使用说明.md》。

双击桌面上的 **拾光日记** 快捷方式，或打开项目文件夹中的：

```text
release\拾光日记\Shiguang.exe
```

如果使用的是免安装 ZIP 包，解压后进入“拾光日记”文件夹，直接双击其中的 `Shiguang.exe`。

程序已包含 .NET 运行时，日常使用不需要 Visual Studio、Python、Node.js 或 Office。请保留 `Shiguang.exe` 旁边的所有文件，不要只复制一个 EXE。程序未做商业代码签名。

首次打开显示当月日历，不会自动加入测试记录。点击右上方“添加”，或点击尚无记录的日期，即可开始。关闭程序后，日记仍保留在独立的数据文件夹中。

宽窗口默认展开左侧导航，窄窗口显示图标。点击左上角的三横线可手动切换。底部固定为“同步”“导出”“设置”。完整说明可从“关于 → 使用说明”打开。进入日记后，点击左上方返回箭头回到浏览页面。

如果要把程序复制到其他位置，请复制整个 `release\拾光日记` 文件夹，重新建立快捷方式。移动程序文件不会自动迁移日记；换电脑请使用加密备份恢复。

## 2. 写第一篇日记

1. 点击右上方“添加”，或按 `Ctrl+N`。也可在月历上点击无记录的日期，为那一天新建日记。
2. 填写可选标题，在正文区域记录内容。展开“日记详情”可修改日期和时间。
3. 点击顶部“格式”图标显示格式工具栏，设置粗体、斜体、下划线、删除线、颜色、高亮、列表、链接和时间戳；工具栏默认收起。
4. 点击正文下方“添加标签”，搜索并勾选标签／人物，也可输入新名称后按 Enter。点击星星设置 1–5 星，再次点击当前星级可取消评分；点击“添加地点”进入地点详情。
5. 使用正文下方的“添加照片”“添加文件”或“添加录音”加入附件。照片以紧凑缩略图横向排列，点击可预览；鼠标悬停查看名称，右键管理附件。
6. 等待状态显示“本地 · 已保存”，也可按 `Ctrl+S` 立即保存。

一天可以创建多篇日记，也可以修改已有日记的日期。完全空白的草稿不会保存；只有标题而没有正文或附件的草稿也不会保存。要删除已有内容，请使用“删除”移到回收站。

正常情况下，停止编辑约 1 秒触发保存；连续编辑约 5 秒提交一次。中文输入法尚未确认的组合文字会等输入完成后再保存。切换日记和正常关闭之前也会保存。出现“保存失败”时，内容会留在当前窗口，不能静默切换或关闭；退出时可以重试、另存当前文字、继续编辑，或经过再次确认后放弃未保存更改。另存文字不包含富文本格式和附件数据；请检查日期格式、磁盘空间和文件权限后重试。

**看到“已保存”代表本机写入成功，不代表云端同步。** 云端结果以同步窗口的状态为准；未配置并执行 Google Drive 或 WebDAV 同步时，日记只保存在本机。

外部复制的富文本按纯文本粘贴，以避免把不受支持的格式或可执行内容带入；在程序中可重新设置格式。剪贴板图片会作为附件保存。正文与附件分区展示。

**插入网页或日记链接：**将光标放在正文中，或选中同一段落内的文字，再点击格式栏“链接”或按 Ctrl+K。选择“网站”输入完整网址，或选择“关联日记”按日期、标题、正文、标签搜索目标记录。显示文字可自定义；留空时使用网址或目标日记的日期和标题。按住 Ctrl 单击正文中的链接即可打开。

打开关联日记前会保存当前修改；保存失败时留在原日记。目标在回收站或已不存在时会提示，恢复目标后原链接可继续使用。关联链接仅在当前拾光日记库内有效，不兼容 Diarium 的私有链接，也不会注册为 Windows 全局链接。完整备份和拾光 JSON 保留富文本中的内部链接；合并导出 HTML／DOCX 时，目标若也在同一文件内，转换为文档内跳转；未包含目标时只保留显示文字。

**语音输入：**展开格式栏后点击“语音输入”可查看指引。关闭提示后正文获得焦点，按 Win+H 使用 Windows 语音输入。识别、联网、语言和麦克风权限由 Windows 管理；程序没有独立语音识别引擎。

## 3. 附件、录音与播放

使用“添加照片”或“添加文件”，也可把资源管理器里的文件拖到编辑区。提供标准位图数据的图片拖放会转为 PNG 附件；浏览器只提供网页地址的拖放不会自动下载图片。拖入附件不会替换正文中的选中文字。程序复制并加密保存文件，移动原文件不会影响已保存的附件。单个附件最多 200 MB；拖入位图还限制解码后像素大小。没有附件数量付费限制。

编辑页照片为 112×112 的小圆角、无边框缩略图，点击可预览。鼠标悬停查看文件名；右键点击缩略图，或在其获得键盘焦点后按 Shift+F10，可查看、另存、重命名显示名称、向前移动或从当前日记移除。非图片附件保留类型和文件名。历史版本仍可能保留已移除的附件。锁定状态和回收站日记不能加入或修改附件。

JPEG、PNG 等 Windows 可解码图片可直接预览。WebP 和部分特殊格式取决于系统编解码器；无法预览时仍可作为文件保存和另存。

### 图片浏览与拍摄信息

点击照片，或点击编辑区“照片信息”，打开当前这篇日记的图片浏览器。“上一张／下一张”以及键盘左右箭头切换照片；滚轮、加减按钮可缩放，拖动图片可平移。“适应窗口”或数字 0 恢复适应大小，“100%”按原像素尺寸显示；“旋转 ↻”或 R 只旋转预览，不改动加密原文件。Esc 关闭浏览器。

底部显示文件名、像素尺寸、照片提供的拍摄时间和 GPS。大图最长边按 4096 像素解码，超过 1.5 亿像素的图像不预览；“100%”仍按原图尺寸布局，不代表大图已经全分辨率解码。损坏或缺少解码器的照片会显示占位，仍可切换其他照片。

要使用照片信息，点击“使用拍摄信息”，明确勾选日期时间、GPS 中需要的项目，再点“应用勾选项”。默认均不勾选。只有勾选的字段会替换当前日记信息；坐标导入保留已有地点名称。没有拍摄日期或 GPS 的照片不能导入对应字段。照片未提供时区时按照片记录的当地时间读取，不自动换算。

### 当天照片建议

1. 进入“设置 → 服务”，在“照片建议目录（本机，不递归子目录）”下点“选择照片文件夹”，再保存设置。
2. 打开要写的日记，在附件区域点击“当天照片”。只检查所选目录顶层的图片，不扫描整台电脑或子目录；每次最多检查 3000 张，可取消扫描。
3. 列表优先按 EXIF 拍摄日期匹配日记日期；没有 EXIF 日期时使用文件修改时间，并明确标注“文件修改时间（没有拍摄日期）”。此回退可能不是实际拍摄日期，请自行核对。
4. 选择照片，可用 Ctrl／Shift 多选，点击“加入日记”后才复制并加密成为附件。

只显示在建议中的文件不会被加入日记备份或云同步。清除建议目录会停止后续扫描，不删除原照片和已经加入的附件。建议目录是本机设置，换电脑后需要重新选择。

点击“添加录音”进入录音窗口，再点击开始才使用麦克风。支持暂停、继续、停止、试听、保存和取消；录音格式为 16 kHz 单声道 WAV，最长 30 分钟。录音在内存生成，点击保存后加密加入当前日记；取消会释放设备并清理缓冲区。真实麦克风权限与长时间录音尚未在交付测试中验证，首次使用请先录制一段短音频检查。

音视频可通过 Windows 媒体组件播放，格式支持取决于系统。播放已有附件时会先提示：为供系统播放器读取，需要生成临时明文媒体文件。正常关闭播放窗口、锁定或退出时会尝试删除，异常终止可能留下 `%TEMP%\shiguang-play-*` 文件。对高度私密内容可不使用此播放方式。图片预览和新录音不需要明文临时文件。

另存的附件是明文文件，请自行保管。

## 4. 找回以前的记录

| 入口 | 用途 |
| --- | --- |
| 今天 | 顶部操作栏按钮；在日历中回到本月，在其他浏览页面中查看今天的全部日记 |
| 时间线 | 按月份分组，日期和时间倒序排列；行内显示日期、正文摘要、标签与首张照片，点击打开整页日记 |
| 日历 | 整页显示六周、42 个日期格；有记录的日期按主题色、标签或评分着色，也可显示照片缩略图，多篇时显示条数。当天只有一篇时直接打开，多篇时进入当天列表；点击空白日期新建日记 |
| 搜索 | 搜索标题、正文、标签、人物，组合日期区间、标签和附件条件 |
| 附件 | 按日期浏览照片网格，按图片／视频／音频／其他文件分类；每页 60 个，可向前或向后翻页查看全部附件 |
| 历史上的今天 | 查看以前年份的同月同日；2 月 29 日仅匹配真实的 2 月 29 日 |
| 地图与地点 | 可选加载内嵌地图查看坐标标记；本地地点列表每页 40 条，可翻页查看全部地点记录 |
| 统计 | 日记数、天数、连续记录、字数、月度记录、标签、评分和追踪值 |
| 回收站 | 恢复或永久删除误删的日记 |

搜索支持中文单字、双字和连续词，英文不区分大小写，`%`、`_` 按普通字符处理。搜索结果突出显示命中的词，正文预览会移到命中处附近。清空查询后恢复普通预览，显示效果不改写保存的正文。拼音、OCR、模糊及语义检索尚未实现。

勾选 **无标签** 可以只看没有普通标签的日记，仍可组合关键词、日期、人物和附件条件。人物分类不算普通标签。选中时会清空并禁用标签输入；取消后可重新输入标签，“清除筛选”会一并取消此条件。

点击左侧“搜索”，或按 `Ctrl+F`，打开搜索框和组合筛选。月历上方箭头可切换月份，点击中间的年月可选日期并跳转到对应月份；右键点击日期可“打开这一天”或“新建当天日记”。日记顶部右侧箭头可在当前列表的记录之间切换。日记左上方的返回箭头会回到相应浏览页面，当天列表的返回箭头回到月历。

“标签与人物”可以重命名、合并或批量移除分类，操作前显示范围并确认。它们都是本地信息，不会读取系统联系人。

附件页上方的“全部、图片、视频、音频、其他文件”显示各类数量，切换分类会回到第一页。点击照片预览，点击照片下方日期返回所属日记，右下角“…”可以预览、查看日记或另存。顶部搜索同时检查日记内容和附件文件名；不支持解码的图片显示占位，原文件仍可另存。没有符合条件的附件时，可切回“全部”或清空搜索。

地点可手工填写，经纬度须同时填或同时留空。“地图与地点”默认只显示本地信息；点击“加载在线地图”后，才向 OpenStreetMap 请求当前范围的地图图块。图块请求会暴露网络 IP 和浏览范围，不发送日记标题、正文或标签。可以拖动地图、用滚轮或加减按钮缩放，点击标记查看并打开关联日记；“显示全部坐标”重新调整范围。“定位”把地图移到所选日记坐标，只有地点文字而没有坐标的记录仍可从下方列表打开。

地图网络不可用时可显示已浏览范围的缓存；缓存由当前 Windows 账户保护。关闭在线地图后停止加载，切换页面或锁定会清理地图内存引用。编辑页的外部地图入口仍会先确认后交给浏览器打开。照片 GPS 可经“使用拍摄信息”明确导入；当前没有自动定位或地名自动补全，底图和标记样式不等同于原版 Diarium 的地图。

展开“日记详情”，点击“添加追踪器”，可创建“数值”或“文字”类型的追踪器，并填写可选单位。每篇日记分别保存其值；在追踪窗口中将某项值留空会移除该篇日记的这项记录。数值使用小数点 `.`，支持负数；单位用来显示，不执行单位换算。

也可直接编辑追踪记录，每行采用 `名称=值`，例如：

```text
体重(kg)=65.2
步数=8200
心情=轻松
```

“统计 → 数值追踪”可选择追踪项目，以及“近 30 天”“近 90 天”“近一年”（365 天）或“全部日期”。图表每个点代表一篇日记中的一个数值，同一天多篇不会被合并为平均值；显示最低、最高和最近值，点击图表或展开“最近记录”可跳到对应日记。文字值、无效数字或日期会跳过并说明数量；单位仅显示，不执行换算。

旧日记中只有名称和值的追踪项，第一次打开追踪窗口时按文字类型保留；不会擅自将旧文字转换为数值。趋势图可读取其中能够解析的数字，但不会改写原值。已定义为数值的项目输入非数值时会阻止保存，修正后按 Ctrl+S。

## 5. 模板与历史版本

内置“空白”“每日回顾”“旅行记录”模板。“模板”页面可新增、修改、删除、设为默认，也可从当前日记创建模板。模板使用后与日记独立，更改模板不修改旧日记。

在已有日记中插入模板时，可预览并确认追加。自定义模板编辑区主要用于纯文本；从日记创建的模板可以保留现有富文本，修改模板正文后按纯文本处理。

“历史”可查看并恢复最近保留的版本。每条日记最多保留 20 个已修改的旧版本，相同内容不重复保存为历史；没有按 30 天自动过期。

删除进入回收站，正文、附件和分类一起保留。回收站目前不会自动按 30 天清理；永久删除需要再次确认。误删内容仍可能存在于你以前创建的备份中。

## 6. 密码、锁定与恢复密钥

未设置主密码时，随机数据密钥由当前 Windows 用户的 DPAPI 保护。复制数据文件到其他 Windows 账户或电脑通常不能直接解锁；同一 Windows 账户下的人可以打开程序。

在左下方“设置 → 隐私”设置主密码，至少 8 位。下次打开或锁定后需要密码。主密码改变时会重新包装数据密钥，不需要重新编辑日记。

“生成 / 更换恢复密钥”会显示一串 64 位十六进制字符。请另行妥善保存；新密钥会替换旧密钥。遗忘密码时，在解锁窗口选择“使用恢复密钥解锁”，随后可在设置中用恢复密钥验证并更改主密码。

`Ctrl+L` 或“锁定日记”可手动锁定并隐藏正文、列表及预览。可设置无操作自动锁定，0 表示关闭。**活动对话框、录音等操作期间会暂缓自动锁定；操作结束后重新计时。** 当前不支持 Windows Hello，也不能保证清除系统或其他程序已经取得的屏幕、剪贴板和内存副本。

本地加密使用记录级 AES-GCM，保护正文、元数据、设置与附件；SQLite 的表结构、随机 ID 和记录数量仍可见，不是 SQLCipher 整库加密。日志只保存错误代码，不上传日记内容。

如果主密码和恢复密钥都丢失，无法承诺恢复本机数据。独立加密备份可以用其备份密码恢复，不依赖原主密码。

## 7. 创建和恢复加密备份

### 手动备份

在“关于”页点击“创建备份”，选择保存位置，为这份 `.journalbackup` 设置独立密码并重复确认。备份包含日记、回收站、保留的历史、模板和引用的附件。完成后程序会重新读取验证，并显示条目、附件数量。

备份密码与主密码是两回事。请保留至少一份位于另一块磁盘或可信云盘上的备份；只放在同一块硬盘无法防止硬盘损坏。备份格式为经过认证的加密容器，不是普通 ZIP。

### 自动备份

在“设置 → 备份”选择已存在的文件夹并设置至少 8 位自动备份密码。程序打开、解锁且空闲约 15 秒后，每日创建一份 `shiguang-auto-日期时间.journalbackup`，默认保留最近 7 份。磁盘断开或权限不足时提示失败，不影响本地写日记。锁定或关闭时不会自动备份；下次满足条件时补做。

自动备份密码在本机加密设置内保存；换电脑仍需要你持有这个密码。请不要把其他日记库的自动备份混入同一保留目录。

### 换电脑恢复

1. 在原电脑手动创建加密备份，保管好备份密码。
2. 将备份和完整程序文件夹复制到新电脑。
3. 打开新电脑的空日记，点击“关于 → 恢复备份”，选择备份并输入密码。
4. 检查预检显示的日期、条目数和附件数。
5. 确认替换后，检查恢复出来的正文、附件和分类，再设置新电脑的保护方式。

恢复会替换当前条目、回收站和历史记录，并恢复日记相关设置；当前电脑的密钥和备份目标、备份密码保留。恢复前自动生成保护快照，位于数据目录的 `recovery-snapshots` 文件夹，**快照密码使用你此次恢复输入的备份密码**。需要撤回恢复时，可再恢复该快照。

错误密码、截断或篡改的备份会被拒绝，不会替换当前库。不要用正在写入的 `journal.db` 文件充当完整备份。

遗忘主密码且只有独立备份时：关闭程序，先完整复制数据目录保留原件，再把原目录改名；重新打开会建立空库，可从独立备份恢复。不要删除原数据来试密码。

## 8. 云端加密同步

点击左侧底部同步图标，或“设置 → 服务 → 云同步 · Google Drive / WebDAV…”，选择提供商。两者均在拾光客户端之间同步，使用独立格式，不读取原版安卓 Diarium 云库；更换提供商不会自动迁移另一个提供商的数据。

### Google Drive

当前没有随程序预置公共 Google OAuth 客户端。先按 [Google Drive 首次配置](docs/Google-Drive首次配置.md) 启用 Drive API、创建个人桌面客户端并下载 JSON；程序内展开“Google 登录配置”导入这份文件。

1. 选择 Google Drive，点击“登录 Google 账号”，在系统浏览器完成授权，回到拾光核对账号邮箱。程序不接收 Google 密码。
2. 填写 8–1024 个字符的独立同步口令。该口令用于加密日记，不发送给 Google；不能通过改口令直接替换已有云库的密钥。
3. 可先“检查连接”，再点击“立即同步”。登录本身不上传日记；检查连接通过也不代表已完成云端写入。
4. 另一台拾光导入同一份桌面客户端 JSON，登录同一 Google 账号，使用同一口令，然后同步。本实现按客户端 ID 和账号划分云库，更换客户端 ID 会进入另一个同步库。
5. 首次同步成功后，按需启用“程序打开并解锁时自动同步”，间隔 5–1440 分钟。只有程序打开、解锁且空闲时尝试；锁定、关闭、休眠期间不会作为系统服务运行。

Google Drive 使用隐藏应用数据区域，不会在“我的云端硬盘”显示普通拾光文件夹。日记、附件和回收站状态加密上传；本机外观、授权、目录、当天动态与版本历史不参与云同步。完整 `.journalbackup` 备份包含设置凭据并由独立备份密码加密，恢复时保留目标电脑授权，不激活来源账号。同步支持并发冲突副本、删除墓碑和已确认提交的缺失/改写检测；远端异常时保留本机日记并停止同步。

“重新登录 / 更换账号”完成后先手动同步，再按需开启自动同步。换账号保留本机日记，下一次同步会将它与新账号的拾光云库合并。“退出账号”只清除此电脑的登录并关闭自动同步，保留本机和云端数据；不会撤销其他设备的 Google 授权。

单附件最多 200 MB，每轮附件传输最多 512 MB，单次加密变更最多 32 MB，总历史最多 256 MB、20,000 次提交，最多 100,000 条记录（含删除标记）。永久删除墓碑、旧提交和不再引用的密文附件不自动回收，尚无历史压缩。取消不会撤回远端已经成功接收的内容，下次同步会重新核对；仍应保留独立加密备份。

Google 授权失效时，程序会暂停自动同步并提示重新登录。配置与排错方法见 [Google Drive 首次配置](docs/Google-Drive首次配置.md)。

### WebDAV

该功能在多台运行拾光日记的 Windows 电脑之间同步，**不兼容安卓 Diarium 或其云端数据格式**。无需日记账号，但需要你自己的 WebDAV 存储账号；不能直接用 OneDrive／Google Drive 网页地址代替 WebDAV。

1. 在服务方建立供拾光使用的 WebDAV 文件夹，取得 HTTPS 地址及用户名、密码或应用专用密码。
2. 打开云同步窗口选择 WebDAV，再打开其配置。填写地址、凭据和至少 8 位的独立同步口令。
3. 点击“检查连接”。检查会在 `shiguang-sync-v1` 子目录创建并清理测试对象，确认读写、强 ETag 和条件写入能力；已有同步库还会检查口令。
4. 点击“立即同步”。成功后检查窗口里的条目、冲突副本、上传和下载数量。另一台拾光使用同一地址、账号及同步口令，再执行同步。
5. 如需定时同步，勾选“程序打开并解锁时自动同步”，设为 5–1440 分钟并保存设置。只在程序打开、解锁且空闲时尝试；关闭、休眠或锁定时不会继续后台同步。

同步包括正文、分类、评分、位置、追踪值、已加入日记的附件和回收站状态；本机外观、服务授权、建议目录、只读当天动态和版本历史不会上传。同步口令用于 AES-GCM 端到端加密，不发送给 WebDAV；它与本地主密码、备份密码各自独立。已有库不能直接通过改口令完成换钥，请保管原口令。

并发编辑会保留“同步冲突副本”；永久删除通过删除标记传播，旧版本恢复可能作为独立冲突副本保留。若本机在同步期间产生新编辑，程序保留新内容并提示稍后重试，不静默覆盖。服务器必须支持强 ETag、If-Match／If-None-Match 条件提交；不兼容的服务会被拒绝，而不会退化为无条件覆盖。单附件最多 200 MB、每轮待传媒体合计最多 512 MB、清单最多 32 MB，超限停止并提示。

同步窗口可取消；取消时已成功提交的远端内容不保证回滚，下次同步会重新核对。失败或断网不等于本地保存失败，可检查服务状态后重试。不要删除或手工修改远端 `shiguang-sync-v1` 文件，也不要让网盘直接同步正在使用的 `journal.db`。同步会传播删除，因此仍需独立备份。

当前没有远端垃圾回收：已不再被日记引用的旧加密附件仍可能占用云空间；永久删除墓碑不自动过期。本机回收站没有定期清理，历史仍按最近 20 个版本规则保留。不要把界面中的“永久删除”理解为已抹除所有旧云端密文、历史备份或其他设备副本。

WebDAV 协议和断网重试已用模拟服务测试。使用自己的服务器时，可在同步设置里先执行一次“立即同步”，查看连接结果。


## 9. 天气与日历动态

在“设置 → 服务 → 天气与日历动态…”打开“服务与动态”。它们作为日记编辑页的“当天动态”显示，不写入正文，也不替你发布或修改事件。

### 天气

勾选“启用日记地点天气”并保存。日记需要有效经纬度，可在“添加地点”中手工填写，或明确导入照片 GPS；程序不会自动定位。启用后查看带坐标的日记时，将坐标和日期发送给 Open-Meteo，服务也会收到网络 IP，不发送正文或标签。

显示天气状况、摄氏最高／最低温度及地点时区的日出日落；支持 1940 年起的历史日期和未来 15 天范围，实际可用日期以服务返回为准。天气是模型资料，可能与实际观测不同。断网时优先显示已缓存资料和缓存状态；缓存由当前 Windows 账户保护。“刷新”会重新读取资料；天气缓存未过期时仍会复用，ICS 会重读文件。该免费接口按服务条款适用于个人及其他非商业用途。

### 本机日历文件

点击“选择 ICS 文件…”，选择日历软件导出的本机 UTF-8 `.ics` 文件，可勾选来源或移除。最多 16 个来源，每个文件不超过 10 MB。程序只读这些文件，不扫描系统日历，不登录 Outlook／Google 账号，不订阅远程日历，也不修改原文件。

支持全天、跨天、UTC／系统可识别 TZID、每日／每周／每月重复，以及 COUNT、UNTIL、EXDATE、RDATE。年度和复杂重复、自定义时区等不支持时会显示具体提示；不要把有警告的结果当作完整日程。源文件更新后，在“当天动态”点击“刷新”。没有对应事件、文件丢失或解析失败会给出状态。来源路径保存在加密设置中，换电脑或恢复备份后保留该电脑本来的服务设置。

## 10. 从安卓 Diarium 迁入

当前支持的是**用户主动导出的数据迁入**，不支持与安卓 Diarium 自动互通。

1. 在安卓 Diarium 中先保留原应用自己的完整备份。
2. 使用 Diarium 的“导出”功能生成 JSON；照片、音视频等附件如需迁移，应另行一并导出。
3. 把导出 JSON 和相关附件复制到电脑，保持原相对目录结构。
4. 在拾光日记先备份现有日记，再点击“关于 → 导入日记”，选择 JSON。
5. 阅读新增、跳过、冲突和警告报告，逐篇抽查日期、标题、正文、标签与附件。

已按作者公开样本适配 `date`、`heading`、`html`、`tags`、`people`、坐标等字段。常见 HTML 格式会转换为安全的富文本；复杂网页结构可能简化。未使用你本人的安卓导出样本验证，因此不能保证所有版本或字段都能无损导入。

JSON 本身没有提供的媒体文件，程序无法凭空恢复。缺失附件或不支持字段会产生警告；部分无效记录可能跳过。不要因为显示“导入完成”就删除安卓原件。

0.7.0 可读取包含完整附件的 Diarium SQLite `.diary` / `.db` 备份；也可在“设置 → 服务 → 从本机 Diarium 导入”读取正版已下载的数据。模板、事件和未适配的标签属性会在报告中提示。云端 `v4_database` 是另一种加密格式，尚不能直接解码，也不直接解析云文件夹 ZIP。一般文件导入上限 128 MB，较大数据可按日期分批导出。

同一导入数据重复导入会跳过相同记录；相同 ID 内容不同会保留冲突副本，不直接覆盖本地版本。导入按条提交，中途中断可能已成功添加一部分；可再次导入并检查报告。

## 11. 导出与通用 CSV

点击侧栏底部“导出”可以导出全部日记。要按当前视图导出，请右击“导出”，选“导出当前视图…”。前者使用全部未删除日记，后者只使用当前筛选结果；月历为当前月份、当天列表为所选日期。编辑页顶部也可“导出这篇日记”。

在导出窗口中选择起止日期、标签、格式及是否包含附件。起止日期都包含在范围内，留空表示不限；多个标签用逗号分隔，默认全部匹配，也可勾选“符合任一标签即可”。窗口会显示实际导出的日记和附件数量。

成功导出后，软件会在本机记住文件格式、是否包含附件、是否逐篇保存。重开软件后继续沿用；取消或导出失败时保留原选项。日期、标签筛选和保存路径每次重新选择。这组偏好独立保存在当前日记库，不通过云同步或完整备份迁移。

不勾选“每篇日记导出为单独的文件”时生成一个合集；勾选后，在所选保存位置建立新的文件夹，为每篇日记生成单独文件，名称包含序号、日期和标题。同名标题不会互相覆盖；逐篇输出全部成功后才发布文件夹，既有文件夹不会被合并或替换。合集需要覆盖已有文件时，由 Windows 保存窗口确认。

| 格式 | 用途 |
| --- | --- |
| TXT | 纯文本阅读和长期保存 |
| HTML | 离线阅读，保留常见格式和图片 |
| DOCX | 用 Word、WPS 或其他兼容程序阅读；生成时不需要安装 Office |
| JSON | 拾光结构化数据与相对附件路径；完整迁移附件时须勾选“包含附件” |
| PDF | 直接生成可阅读、可检索的 PDF，包含常见富文本及照片；支持合集和逐篇保存 |

勾选“包含附件”时，导出文件和 `<文件名>_附件_<随机字符>` 文件夹需要一起移动；逐篇导出应保留整个生成的文件夹。不勾选时不写附件文件，也不保留指向缺失附件的清单，原日记不变。仅有照片而没有正文的日记不能通过不含附件的 JSON 完整迁移。

JSON 导回可保留稳定 ID；它不包含完整历史、回收站和密钥，不能代替完整加密备份。Word/HTML 支持常见富文本，复杂排版仍应打开检查。同一合集中的内部日记链接转换为 HTML 锚点或 Word 书签链接；目标未选中或被分到其他文件时，仅保留显示文字。不会调用 Windows 自定义协议打开这些导出链接。

选择 **PDF 文档（直接保存）** 后选择保存位置即可生成文件，无需打印机或浏览器。长文自动分页，照片保持比例；勾选“包含附件”时，PDF 显示照片，原始照片和其他文件保存在配套附件文件夹中。中文和英文正文保留为文本，可在 PDF 阅读器中搜索、选择和复制。

PDF 支持粗体、斜体、下划线、删除线、文字颜色、高亮、列表和链接。复杂表格、嵌入对象和彩色 emoji 尚未完整支持；这类内容导出后请打开检查。

**TXT、HTML、DOCX、JSON、PDF 和附件导出均为明文。** 需要加密迁移时使用 `.journalbackup`。

通用 CSV 使用 UTF-8，至少包含 `date,text`，可选 `title,time,tags,people,rating,location,latitude,longitude,id`。推荐日期 `yyyy-MM-dd`，时间 `HH:mm`；标签和人物使用分号分隔。含逗号或换行的字段必须加双引号，字段内双引号写成两个双引号。例如：

```csv
date,time,title,text,tags,people,rating
2026-10-26,21:00,普通的一天,"散步，读书，给自己一点时间。",日常;阅读,,4
```

## 12. 外观、提醒与快捷键

“设置 → 外观”可选择浅色、深色或跟随系统、主题色，以及正文字体和字号。主题色可点选色块或输入 #RRGGBB；常用字体显示中文名称，也可输入其他字体名。下方“外观预览”会随选择实时更新示例文字和标签，点击“保存设置”后应用到主界面。跟随系统以应用打开或刷新设置时为准。

所选字体用于正文、日记标题及编辑页日期标题。悬停、选中状态与强调文字会跟随主题色；深色模式也覆盖日期选择弹窗、展开箭头、单选和勾选控件，以及设置窗口标题栏。时间线摘要保留正文换行，标签与人物逐个连续排列和换行。

“设置 → 提醒”可设置每日书写目标，范围为 0–100000 字／词，0 表示关闭。编辑页底部显示所选日期的合计进度；同一天多篇合计，回收站不计入，达到目标显示勾号。中文按汉字、英文按词计数。

提醒只在程序打开、解锁且没有阻塞对话框时运行，可选择当天已有记录不提醒；关闭程序、休眠、系统通知和开机启动提醒均未实现。

主界面默认采用蓝色标题栏和操作栏，浅色主题使用白色内容行及浅灰背景，深色主题使用深灰内容区。左侧图标栏可以展开或收起；日历、列表和正文各使用完整内容区域。窗口默认尺寸为 1200 × 850，最小为 760 × 560，也可最大化使用。

## 13. 文件位置、升级和卸载

正式日记数据默认位于：

```text
%LOCALAPPDATA%\ShiguangJournal
```

可从“设置 → 关于”查看实际路径并打开。重要文件包括 `key.json`、`journal.db`、`attachments`，它们应作为整体保留。日记打开时还可能出现 SQLite 的 `-wal`、`-shm` 文件，不要单独删除。

升级前创建加密备份，保存并退出程序。安装版运行新版安装包；免安装版替换整个程序文件夹。本分享包的 0.9.1 会沿用原来的数据目录，不需要重新导入日记。新安装时 Google 设置默认为未配置、未登录、不开启自动同步。已有 WebDAV 和其他本机服务配置继续保留。备份恢复保留当前电脑的云提供商、同步凭据、服务开关、日历来源和照片目录，不会直接激活另一台电脑的服务。当前没有自动更新、MSIX 安装器或通用的跨版本数据库升级流程。

卸载免安装版：退出后删除程序文件夹和相应快捷方式即可。数据目录不会随之删除，下次运行仍会读取。真正要移除个人数据时，请先验证备份，再自行处理上述数据目录及备份；程序不会替你自动清空个人日记。

## 14. 当前限制与问题处理

当前按个人中小规模日记设计。尚未完成任务书要求的 10 万条、50 GB 媒体性能验证、48 小时离线耐久、所有 DPI/显示器/Narrator、真实跨 Windows 账户、磁盘满、恢复过程中断电和 10 分钟真实录音测试。大批量附件、备份和导入会暂时占用界面，尚无完整进度取消机制。

安卓 Diarium 双向互通、OneDrive、Dropbox、iCloud、系统日历直接接入、Windows Hello、小组件和退出后的系统提醒仍待实现。

如果保存失败：先保留窗口和正在写的内容，检查日期/时间、经纬度、追踪器格式、磁盘空间和权限；修正后按 Ctrl+S。不要直接结束进程来解决未保存问题。

如果文件损坏或无法解锁：不要修改 `key.json`，也不要删除数据库；保留原目录，用已验证的加密备份恢复到新库。

“设置 → 关于 → 导出脱敏诊断信息”可以导出版本、系统版本和错误代码。诊断不包含日记正文、标题、密钥、完整数据路径或访问令牌，默认不上传任何服务。
