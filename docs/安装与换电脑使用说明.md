# 拾光日记：安装与换电脑使用

适用安装包：拾光日记 0.9.1，Windows 11 x64。安装包自带 .NET 10 桌面运行时，无需安装 SDK 或另外下载运行时；本地日记功能可以离线使用。Windows on ARM 的 x64 模拟运行尚未实测。

## 在新电脑安装

1. 将拾光日记 0.9.1 的 x64 安装包复制到新电脑，双击运行。
2. 按中文安装向导继续。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\ShiguangJournal`，不需要管理员权限。
3. 按需要勾选“创建桌面快捷方式”，完成安装后从开始菜单打开“拾光日记”。
4. 新电脑首次打开是空日记库。安装包不携带任何人的日记、密钥、Google 账号或同步口令。

当前安装包没有商业代码签名证书；若 Windows 显示“未知发布者”，可先使用安装程序旁的 `.sha256` 校验文件核对包。安装程序不会修改 Windows 安全设置。

## 把旧电脑的日记迁移过来

1. 在旧电脑的拾光中打开“关于 → 创建备份”，创建使用独立密码加密的完整 `.journalbackup` 备份，并记住该备份密码。
2. 将备份复制到新电脑。在新电脑的拾光中选择恢复备份，输入备份密码，核对日记和附件。
3. 恢复会替换目标日记库内容；若新电脑已写了日记，请先在新电脑另做备份。

默认本机密钥受当前 Windows 用户的 DPAPI 保护，不能依赖直接复制 `%LOCALAPPDATA%\ShiguangJournal` 或 `key.json` 到另一电脑来完成迁移。使用完整加密备份可跨设备恢复，旧电脑内容不因新电脑安装而改变。

也可以在两台拾光中配置同一 Google Drive 或 WebDAV 云库来合并日记。Google Drive 需导入同一份桌面客户端 JSON、登录同一 Google 账号，并使用相同独立同步口令；新电脑需要自行登录授权。步骤见 [Google Drive 首次配置](docs/Google-Drive首次配置.md)。拾光云同步不能读取原版安卓 Diarium 的私有云数据。

## 升级和卸载

- 升级前保存并关闭全部拾光窗口，再运行新版安装包；默认沿用此前安装目录。
- 日记数据独立保存在 `%LOCALAPPDATA%\ShiguangJournal`，不在程序安装目录里。
- 可通过 Windows“设置 → 应用 → 安装的应用 → 拾光日记”卸载，或使用开始菜单中的“卸载拾光日记”。
- 卸载会移除安装的程序、快捷方式和卸载注册项，**保留日记、附件与本机设置**，以便重装后继续使用。卸载也不会删除 Google Drive 或 WebDAV 云端数据。
- 安装或卸载检测到拾光正在运行时，会要求先保存并关闭；不会强制结束日记进程。

完整功能和限制见 [使用说明](使用说明.md)。
